Sourabh Torgal — Personal Blog
A modern, responsive personal blog website built with HTML, CSS, and JavaScript. This project is a personal corner of the internet for sharing life experiences, reflections, personal growth, and meaningful moments.
✨ Features
Modern dark theme with navy, blue, and cyan accents
Responsive layout designed for desktop, tablet, and mobile screens
Mobile navigation menu with a simple toggle interaction
Hero section introducing the blog and linking to key sections
About section for a short personal introduction
Experiences section organised around beginnings, growth, and memories
Journal section with starter reflections that can be replaced with original posts
Contact section with an email link
Automatic copyright year using JavaScript
Smooth scrolling and subtle hover effects
🛠️ Built With
HTML5 — page structure and content
CSS3 — layout, responsive styling, gradients, and visual effects
Vanilla JavaScript — mobile menu interaction and automatic footer year
Google Fonts — DM Sans and Space Grotesk
